    From OpenClaw to Your Own Assistant

    June 04, 2026
    #claude #openclaw #obsidian
    A personal assistant should be like a person: one channel, one conversation — it answers everything you ask in a single ongoing thread; in this project that channel is Telegram by default. Under the hood, it's an evolving knowledge base, wired into the network, that happens to talk back. The bet: own the one layer that doesn't churn — your data. The model keeps evolving, the harness is throwaway glue, even the CLI underneath could swap out — but the folder stays yours. …
